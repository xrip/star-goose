# Provenance

The assembly and analysis in this package were derived from the executable in the user-provided `goose.zip`. The original binary contains the strings `Star Goose (C) 1988 Logotron Ltd` and the game resource filenames.

Descriptive procedure and variable names were added during reconstruction; they are not original debug symbols. This package does not claim recovery of the authors' original source text or a license grant from the original rights holders. Existing rights in the game code and resources are unchanged. No separately sourced game executable or game assets were used.

The build and verification helper was written for this reconstruction. It does not run the DOS program. The bundled executable is the result of assembly, and was compared directly against the supplied original.
