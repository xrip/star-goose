# Проверки версии2

## Побайтовая проверка

Обе сборки — модульная и flat — дают53 684 байта и SHA-256 `631ffed20bb29e564b455d9185220d30dc1c35964bd9f7aeb421cad4567c4a0b`. Проверены MZ-заголовок, четыре DOS-relocation, таблица35 handlers, исходные ресурсы. Объект ELF после сборки flat-source не содержит неразрешённых объектных relocation; их не следует путать с четырьмя DOS-записями внутри EXE.

## Структура и навигация

Все6022 записи `analysis/instructions.json` указывают на настоящую текущую строку в модульном исходнике. Все204 именованных входа проверены по меткам и контрактам. Старое ошибочное сопоставление `[si/di+7]` строке сообщения удалено. RLE24 частей декодируется в12×64; 9029 токенов и496 размещений воспроизводятся без изменения.

Flat-source собирался в отдельной временной папке, где не было ни оригинального EXE, ни include-файлов, ни resources. Проект также пересобирался после распаковки архива с удалённым каталогом build. Специальная порча одного байта проверяет, что verifier действительно отклоняет несовпадение.

## Начальные C-модели

Скомпилированы C11 с `-Wall -Wextra -Werror -pedantic`. Проверены4135 round-trip сериализаций Entity (39 оригинальных шаблонов и4096 произвольных записей),279 кадров,3 сценария пула,524288 случаев арифметического сдвига,65536 случаев горизонтального шага и256 входов tunnel force,2 отклонения некорректного буфера.

Это проверка отдельных моделей данных/арифметики, **не запуск оригинальных x86-процедур** и не differential-тест всей игры. Полного DOS-запуска, визуального прохождения и эталонной трассы кадров здесь нет. Утверждение byte-exact относится к ASM-бинарнику; семантические комментарии и будущий C-код имеют отдельный уровень проверки.

Машиночитаемый итог: `analysis/VALIDATION_V2.json`; отчёты выполнения — `build/verification.json`, `build/project_tests.json`, `build/c_model_tests.json`.
